
# MediGuard

MediGuard is an event-driven risk analysis platform that analyzes real-time medical prescriptions, performing instant drug-drug interaction (DDI) checks and pediatric dosage anomaly detection.

## Project Architecture

```text
Reference Data (drug_reference_loader.py)
    ↓
PostgreSQL (mediscope.drugs) — 20k+ pharmaceutical records
    ↓
Synthetic Patient Generator (patient_generator.py)
    ↓
PostgreSQL (mediscope.patients) — age/weight scaled profiles
    ↓
Event Generator & Risk Validator (prescription_generator.py)
    ├── [Check 1] Pediatric Dosage Rules (Weight-based)
    └── [Check 2] Drug-Drug Interaction Matrix
            ↓
            ├── If Conflict Detected ➔ Blocked & Logged
            │       ↓
            │    PostgreSQL (mediscope.alerts)
            │
            └── If Approved ➔ Passed to Streaming Pipeline
                    ↓
                PostgreSQL (mediscope.prescriptions)
                    ↓
                Kafka Producer
                    ↓
                Apache Kafka (prescriptions_stream topic)

```

## Quick Start

### Prerequisites

* Docker Desktop (must be running)
* PowerShell or Command Prompt (Windows)

### 1. Clone the Repository

```bash
git clone https://github.com/esmabaylan/MediGuard.git
cd MediGuard

```

### 2. Start the Infrastructure & Load Data

Run the initialization script. This starts all Docker containers, loads 20,000+ real drug references, and generates realistic patient profiles:

```cmd
.\init_setup.bat

```

### 3. Start the Real-Time Risk Engine

Start the main application that generates prescriptions, runs them through the interaction matrix, logs alerts, and produces valid events to Kafka:

```bash
docker exec -it mediscope_core python main.py

```

### 4. Stop the System

```bash
docker compose down

```

> **Note:** Use `docker compose down -v` only if you want to completely destroy the database volumes and reset the environment from scratch.

## Database Schema

```text
mediscope
└── public (schema)
    ├── drugs                → reference table (categories, weight_based flags)
    ├── patients             → demographic data (age, weight, chronic diseases)
    ├── prescriptions        → successfully validated prescription records
    └── alerts               → blocked transactions (DDI rules)

```

## Developer Notes

* Database tables are auto-generated by SQLAlchemy during the initial execution of the scripts

* The `prescription_generator.py` acts as a strict gateway. It cross-references the patient's existing `prescriptions` history against a predefined `INTERACTION_RULES` matrix.

* Pediatric dosage logic scales down adult limits automatically using WHO-referenced weight distributions generated by `patient_generator.py`.
